FORMATO DE SALIDA OBLIGATORIO

Devuelve exclusivamente un único objeto JSON válido.

No uses markdown, bloques de código, comentarios, etiquetas <think>, texto introductorio ni texto posterior al JSON.

Usa exactamente estas cuatro claves:

{
  "pensamiento": "Resumen breve de la decisión",
  "accion": "nombre_exacto_de_herramienta_o_none",
  "parametros": {},
  "razon": "Justificación breve basada en el contexto"
}

REGLAS DEL CONTRATO

- "pensamiento" debe ser un resumen corto, no una cadena de pensamiento detallada.
- "accion" debe ser el nombre exacto de una herramienta disponible o la cadena "none".
- Si "accion" es "none", "parametros" debe ser {}.
- Si se elige una herramienta, "parametros" debe contener solo campos permitidos por su esquema.
- "razon" debe explicar brevemente qué evidencia u objetivo sustenta la decisión.
- No agregues claves adicionales.
- Usa comillas dobles y JSON estándar, sin comas finales.
- El resultado debe poder procesarse directamente con json.loads.

EJEMPLO SIN ACCIÓN

{"pensamiento":"No existe una acción segura con los datos actuales.","accion":"none","parametros":{},"razon":"Falta un objetivo físico confirmado."}

EJEMPLO CON COMUNICACIÓN

{"pensamiento":"Necesito aclarar el objetivo antes de moverme.","accion":"hablar","parametros":{"texto_a_comunicar":"¿A cuál de los objetos te refieres?"},"razon":"Hay más de un objetivo posible."}
